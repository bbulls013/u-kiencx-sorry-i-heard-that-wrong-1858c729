Entry for the make.fun bounty "Sorry, I Heard That Wrong": a single-line apology a smart speaker gives its owner after mishearing them. The program writes one line (at most 140 characters) to `entry.txt` in `OUTPUT_DIR` (fallback `.`) and prints it. Stdlib-only and deterministic.

## Run

```bash
python3 main.py
# or with a custom output directory:
OUTPUT_DIR=/tmp/out python3 main.py
```
